# Portfolio handoff pack

Start a new chat, attach **PORTFOLIO-CONTENT.md**, and say something like:

> Here's all my content and assets. Build me a portfolio site with a
> [describe the design you want]. The images and videos are in this repo
> under `images/` and `videos/`.

## What's here

- **PORTFOLIO-CONTENT.md** — every piece of copy, all the numbers, links,
  testimonials, brand colours, fonts, the full asset list, and a record of
  which designs have already been tried and rejected.
- **assets/** — a copy of every image used on the site, so the folder works
  on its own if you move it off GitHub. Videos are not duplicated here
  (they're large); they live in `videos/` in the repo root.

## Asset URLs

Anything in the repo can be linked directly:

```
https://raw.githubusercontent.com/sanchali07/portfolio-/main/images/hero-stairs.jpg
https://raw.githubusercontent.com/sanchali07/portfolio-/main/videos/reel-1.mp4
```

## The current site

`index.html`, `style.css` and `script.js` in the repo root. Keep them as a
reference or delete them — the content pack is independent of them.
